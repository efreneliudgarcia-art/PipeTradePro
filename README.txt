PIPE - upload these files to GitHub from your phone

1. In Chrome, open github.com and go to your Pipe-Trades repo.
2. Tap Add file, then Upload files, then choose your files.
3. Select every file in this folder (long-press one, then tap the rest), and upload.
4. Tap Commit changes.
5. Turn on Pages once: repo Settings > Pages > Branch: main, folder: / (root) > Save.
6. After a minute or two, open https://YOUR-NAME.github.io/Pipe-Trades/ and use Chrome's menu: Install app.

To update later, upload the new files the same way. Installed copies show an Update button.
